# 竞衡 · 前端展示优化方案 v1.0

2026-11-08 · 已实施，见[验证记录](../VERIFICATION.md)

配套草图：[前端展示优化草图.html](前端展示优化草图.html)（浏览器直接打开，可切换 8 个画面，“亮分（播放）”按现有节奏演示动效）。

## 一、目标与边界

本轮只调整展示层：投屏大屏、评委手机端，以及后台中与展示直接相关的部分。计分规则、亮分时序（1.5 / 3.1 / 4.3 秒）、PPT 式无按钮推进、快捷键、重评与同分流程都保持不变。唯一的流程改动是已确认的“团体奖按奖级逐页、三等奖 → 二等奖 → 一等奖倒序揭晓”，需要同步修改服务端翻页规则。

视觉延续 DESIGN.md 的蓝白体系：警察蓝 #103b75、交互蓝 #1457a6、得分科技蓝 #0969c9、浅蓝底 #f2f6fc。新增的只有颁奖页的深蓝底（#0c2b57）和金银铜三色点缀，均已确认。不引入图片、渐变、粒子、循环动画等装饰。

## 二、现状问题（基于 1920×1080、1366×768、390×844 实测截图）

**画面利用率低。** 打分页内容整体靠 `margin: auto` 居中，1080p 下上方约 260px、下方约 250px 空白；评委卡片固定 175px 高，分数只有 44px，在会场后排很难读清。排名页和颁奖页同样只占画面中间三分之一。

**评委信息不是主角。** 打分页上队名和右侧色块占据视觉重心，评委卡片反而是次要层级。7 位评委排成一行时卡片窄而矮，分数字号受限；30 位评委时卡片挤在中部，下方空出近 200px。

**层级与位置不统一。** 状态标签（评分中 / 剔除极值 / 评分结果）浮在队名上方，测试 / 正式 / 轮次信息在不同阶段出现位置不同；页码只在部分页面出现，样式也不一致。

**排名页偏“表格”而非“榜单”。** 名次用小圆标，队名 26px、分数 36px，与普通后台表格差别不大；看不出谁获得了哪个奖级。

**颁奖页缺少仪式感且分页不合理。** 团体奖按“每页 3 支队伍”混排，一等奖和二等奖可能挤在同一页，三等奖被挤到第二页；视觉与排名页同为浅底卡片，切换到颁奖时没有“进入典礼”的感觉。

**评委手机端输入区偏弱。** 输入框内数字只有 26px，范围说明藏在标签里，超出范围要等提交后才报错；提交后看不到提交时间，也不知道下一队是谁。

**后台“当前大屏”预览不等于真实大屏。** 预览直接把舞台组件塞进后台内容区，比例和字号都与投屏不同，个人奖卡片在预览里反而比投屏还大。

## 三、统一舞台框架

所有投屏画面（打分、排名、团体奖、个人奖、候场 / 休息）改为同一个三段式网格：页首 96px、主体占满剩余高度、页脚 40px。

页首左侧固定为赛事名称；右侧固定为“上下文”信息：打分时显示“测试评分 / 正式比赛 · 第 2 / 3 轮”与“第 3 / 6 队”，排名时显示“最终成绩”，颁奖时显示“团体奖项 / 个人奖项”。原先浮在队名上方的阶段标签保留在队名上方，但只表达亮分阶段（评委评分中 → 全部亮分 → 标记最高 / 最低分 → 剔除极值 → 评分结果）。页脚统一放页码，单页时留空。

字号改为随视口高度缩放（以 `clamp()` 结合 `vh` 实现），同一套规则覆盖 1920×1080、1366×768 以及 1024×768 的 4:3 投影，保证投屏时不出现滚动条。字体沿用 Score Sans（数字）与系统中文无衬线字体，不增加外部字体。

> 页首右侧显示“第 3 / 6 队”，按实际出场顺序计算。

## 四、打分界面：突出各评委打分

布局自上而下为：队伍行（左侧序号 + 队名，右侧结果色块）、评分进度条、评委网格。评委网格占据主体剩余全部高度，是本页的视觉主体。

**评委网格自动排布。** 列数按评委人数计算，让卡片保持横向比例并尽量放大数字：5 人及以下单行；6–12 人两行（7 人为 4 + 3）；13 人及以上三行，每行最多 10 张；超过 30 人时继续加行。行高均分剩余高度。评委分数字号在 7 人时约 96px（1080p），30 人时约 44px，均大于现状。

**评分进行中。** 卡片只显示评委序号和“已打分 / 未打分”，已打分卡片变为浅蓝底；某位评委刚提交时，该卡片有一次 300ms 的底色过渡，不做缩放或弹跳。进度条为分段式，一段对应一位评委，与右侧色块里的“已提交 4 / 7”互相印证。仍不显示任何分值。

**亮分。** 时序不变。全部亮分时，各卡片分数按评委序号依次出现（每张间隔 40ms，30 位评委也在 1.2 秒内完成，不影响 1.5 秒后的极值标记）；标记阶段，最高 / 最低分卡片转为琥珀色边框，右上角出现“最高分 / 最低分”角标；剔除阶段卡片轻微缩小、转灰，分数加删除线，角标改为“已剔除”，被剔除的分数保持可读、可核对（灰色大号数字对比度约 3.5:1，满足大字号要求；角标底色实施时加深到小字也满足 4.5:1）；最后右侧色块放大出现本轮得分或最终得分。

**结果色块。** 宽度固定下限，避免从“4 / 7”切换到“87.80 分”时整行跳动；数字与“分”单位保持在同一基线，不会折行。

**主持人确认亮分模式**（“评分已收齐 · 等待公布”）沿用现有逻辑，仅套用新样式。

## 五、排名界面：突出最终得分与名次

从表格改为榜单：每支队伍一行，依次为大号名次数字、队名、所获奖级标签、最终得分。

前三名的名次数字分别用金、银、铜色，行左侧加 8px 同色竖条；第一名行底色略深以示区分。得分统一使用科技蓝等宽数字，1080p 下约 60px。奖级标签（一等奖 / 二等奖 / 三等奖）直接取自现有获奖数据，让观众在排名页就能把名次和奖项对应起来；未获奖的行不显示标签。

行高均分画面高度，每页最多 8 行（与现有分页一致）；队伍少于 4 支时自动加大字号。入场时从末位向首位依次出现（每行间隔 70ms），第一名最后出现。后台“成绩排名”页复用同一组件，只是不撑满屏幕；手机端名次、队名、得分三列保留，奖级标签移到队名下方。

## 六、颁奖界面：突出仪式氛围

**底色与配色。** 团体奖与个人奖两个阶段整体切换为深蓝底（#0c2b57），页首顶边线由警察蓝改为金色。卡片使用略浅的深蓝（#133a6d），顶部 4px 边条取所属奖级的金 / 银 / 铜色。文字白色，队员名单使用浅蓝灰，保证投影后对比度不低于 4.5:1。

**团体奖逐级揭晓（服务端规则调整）。** 每个奖级单独一页，按三等奖 → 二等奖 → 一等奖顺序推进，一等奖压轴；没有获奖队伍的奖级自动跳过。同一奖级超过 4 支队伍时，在该奖级内继续分页（每页 4 支）。页面中央是大号奖级名称（两侧细线，用奖级色），下方是获奖队伍卡片（队名 + 队员名单）。只有一支队伍时卡片居中放大。

**个人奖。** 奖项名称金色，获奖人姓名为画面最大字号（3 人时约 96px）。1 人时单卡居中放大；2–3 人一行；4–6 人两行；超过 6 人分页。备注（如有）以小字显示在姓名下方。

**动效。** 每翻到一页，奖级名称先出现（700ms），获奖卡片随后依次出现（间隔 180ms）。这是颁奖页唯一的自动动效，不做循环、闪光或粒子。左方向键回看时直接显示最终状态，不重播动画。

## 七、评委手机端

输入区改为大号数字（约 56px）居中显示，标签下方常驻“0–100 分，最多两位小数”；输入超出范围或小数位过多时就地变红提示，提交按钮同时禁用，不再等提交失败才报错。提交按钮固定在屏幕底部拇指区，至少 56px 高。

提交后显示大号分数、提交时间和“已锁定，如需修改请联系管理员”，并在下方提示“下一队：第四代表队”（由评委端已有的项目列表计算，无需新接口）。顶部栏精简为“评委 01 + 连接状态”。仍不增加二次确认，草稿保存、断网恢复等逻辑不变。

## 八、后台相关调整

“大屏控制”页的“当前大屏”预览改为 16:9 的实时缩略画面（内嵌只读大屏并等比缩放），所见即投屏所得，替代现在比例失真的直接渲染。比赛控制台、项目表等其他后台页面只做与新样式的一致性修整（间距、字号层级、状态标签颜色），不调整信息结构。

另有一处小问题一并修正：比赛结束后，控制台“评委席状态”仍显示“待评分”，改为不显示提交状态或显示“比赛已结束”。

## 九、响应式策略

| 场景 | 处理 |
| --- | --- |
| 1920×1080 投屏 | 基准设计尺寸，所有画面无滚动 |
| 1366×768 笔记本 / 投屏 | 字号随高度缩放，30 位评委与 8 行排名均无滚动 |
| 1024×768 等 4:3 投影 | 打分页结果色块移到队名下方横排；评委网格列数相应减少 |
| ≤680px 手机查看大屏 | 单列流式布局，允许纵向滚动；评委卡片两列，排名保留三列 |
| 评委手机端 | 以 360–430px 宽为主，提交按钮固定底部，适配安全区 |
| 打印 | 沿用现有浅色打印样式，颁奖页打印时改回白底 |

## 十、动效原则

只对“状态发生变化”的时刻做动效：评委提交、亮分四阶段、排名入场、颁奖翻页。全部只使用透明度与位移 / 缩放，时长 200–700ms，缓出曲线，无循环动画。`prefers-reduced-motion` 下保留全部阶段顺序和时序，只取消运动与过渡。亮分时序与“未完成动画不能推进下一步”的规则不变。

## 十二、验收方式

全部现有单元测试与浏览器测试通过，新增分页用例通过。在 1920×1080、1366×768、1024×768、390×844 四种尺寸下，分别以 7 位和 30 位评委走完“测试 → 正式 → 排名 → 团体奖 → 个人奖”全流程并截图，与本方案草图逐项比对；减少动效模式下复核阶段顺序；颁奖深蓝底下的文字对比度逐项核对。完成后提供前后对比截图。

## 十三、实施取值

1. 投屏页首显示当前队伍进度。
2. 排名页显示实际奖级，未获奖队伍留空。
3. 后台“当前大屏”采用 16:9 实时只读预览。
4. 个人奖按后台录入顺序展示。
